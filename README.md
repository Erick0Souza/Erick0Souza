# `> PROJETO_PRINCIPAL`

## 📦 Controle de Estoque

**Java 17 • Spring Boot • PostgreSQL • Spring Security • JWT • Docker**

Sistema web para gerenciamento de estoque desenvolvido com estrutura próxima de aplicações reais, incluindo segurança, regras de negócio, testes automatizados e automação de build.

```text
API         REST • Swagger / OpenAPI
SEGURANÇA   Spring Security • JWT • BCrypt • Perfis de acesso
DADOS       Spring Data JPA • Hibernate • PostgreSQL • H2
TESTES      JUnit 5 • Mockito • MockMvc • Spring Boot Test
DEVOPS      Docker • Docker Compose • GitHub Actions
```

### Principais funcionalidades

- autenticação e autorização com JWT;
- perfis de acesso `ADMIN`, `OPERADOR` e `CONSULTA`;
- gerenciamento de produtos, categorias e movimentações;
- regras de entrada, saída e validação de estoque;
- filtros, paginação e ordenação;
- auditoria de ações;
- dashboard administrativo;
- relatórios e exportações;
- testes automatizados;
- ambientes separados para desenvolvimento, testes e produção;
- pipeline de CI com GitHub Actions.
